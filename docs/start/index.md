# Start Here

Welcome back to math. This time it goes differently, for three reasons:

1. **Nothing is assumed beyond high school.** Every lesson lists what it needs, and every prerequisite is on this site.
2. **Everything is motivated.** You'll always know *why* a concept exists and where it's used, before being asked to work hard on it.
3. **The path is short and ordered.** Topics that don't pay off for ML, algorithms, information theory or physics are left out. Topics that do are explained completely.

## Your first hour

1. Read [How to learn this without losing again](how-to-learn.md) (10 minutes). It's the most important page on the site.
2. Look at [the roadmap](roadmap.md) to see the whole journey and pick a track.
3. Start [Phase 1: Foundations](../foundations/index.md). Even if it looks easy, do the exercises. The point of Phase 1 is learning to read and write proofs, and that skill is what made university math feel impossible the first time.

## Warm-up: are you ready?

You should be comfortable with these. If any feel rusty, the first lesson that uses them recaps them.

- [x] Algebra: expanding $(a+b)^2$, factoring, solving $ax^2+bx+c=0$
- [x] Fractions, exponents, square roots: $\frac{a}{b}+\frac{c}{d}$, $x^{a}x^{b}=x^{a+b}$
- [x] Lines: slope, $y = mx + c$
- [x] Basic geometry: Pythagoras, similar triangles, area of a circle
- [x] What a function and its graph are

That's it. Everything else is built here.

!!! tip "A promise"
    At no point will this site say "it can be shown that…" about something you need. If a result is used, either it's proved, or you're told plainly that the proof is beyond the scope of the site and why it's safe to trust it.
